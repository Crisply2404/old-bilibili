# 方案

2026-11-16 定下，还没有代码。讨论过程见 [CHAT_HISTORY.md](CHAT_HISTORY.md)。

## 做什么

把 B 站**电脑网页版**首页的推荐，换成 2018 年以前的老视频，最有古早野生感的先出现。做好以后在 B 站宣传，给网友们一起用。手机 B 站 App 改不了。

## 已经定下的规则

- **老视频 = 内容是 2018 年以前做的。**
  - 2018 年以前上传到 B 站的，算。
  - 2018 年以后才上传、但能看出是老片搬运的，也算：标题或简介写了优酷、土豆、原发年份，或者画面上有老水印。记下原片年份。
  - 故意做旧的新视频（比如 2022 年那种假水印、假相机日期的视频），暂时不推荐。
- **首页只放老视频**，不混入关注的人的新视频。
- 以后如果做个性化，也只推老视频：按网友自己喜欢的内容推相关的老视频，比如他关注的 UP 主早年的视频。

## 两个脚本

| | 建池脚本 | 首页脚本 |
| --- | --- | --- |
| 谁装 | 只有维护者 | 网友 |
| 做什么 | 在维护者自己登录的浏览器里慢慢找老视频、打分，导出成“老视频池” | 把首页推荐换成池子里的视频 |
| 请求 B 站接口 | 很慢：每 3–5 秒一个，每天有上限，一遇到风控（错误码 -352、-412）就停几个小时 | 不请求接口，只像平时一样加载封面图 |

分开的好处：

- 网友装的脚本里没有任何爬取代码，看一眼就知道它不会拿账号去请求什么。用的人再多，也不会给谁招来风控。
- 两个脚本都在 bilibili.com 页面里运行，登录状态由浏览器自己带，cookie 不离开浏览器，也不经过任何第三方服务器。

## 老视频池

- 一个 JSON 文件，跟着首页脚本一起发布，几千条也就几百 KB。
- 每条记：BV 号、标题、UP 主、封面、时长、B 站上传时间、原片年份、来源（B 站原创，或者从哪里搬运）、播放量、野生分、有没有人工审过。
- 只放公开视频的信息，不放维护者的收藏夹导出、关注列表和 uid。
- 定期复查，失效的视频移出池子。

## 建池流程

1. **种子**：维护者的「老视频」收藏夹；其他收藏夹里 2018 年以前的视频；关注列表里 2018 年以前就在发视频的 UP 主。
2. **往外找**：
   - UP 主最早的投稿（投稿列表翻到最后几页，这个接口风控最严）；
   - 老视频的相关视频（试过一次，40 个里 8 个是 2018 年以前的）；
   - 搜索按发布时间筛（参数 `pubtime_begin_s` / `pubtime_end_s`，还没实测）；
   - 分区按时间段排行（`newlist_rank`，不登录试过一次返回 -10，要在登录状态下再试）。
   - 不随机抽 av 号：大半是失效视频，浪费请求。
3. **筛年份**：按上面“老视频”的规则。
4. **机器打分**：年份越早越高；原始分辨率低（老视频常见 640×360、4:3）；标题有当年的腔调（【解说】、实况、坑爹、节操、渣操作、杯具、神马）；简介里有优酷、土豆、QQ 群；是个人 UP 主不是机构号；播放量不太高（野生不等于爆款）；弹幕里有「前来考古」「十年了」「我还在」。
5. **AI 打分**：把标题、简介、封面和一页弹幕给模型，按下面的标准打 1–5 分，附一句理由。
6. **检验**：维护者「老视频」收藏夹里的视频，大多应该排在前面；排不上去就调标准。
7. **人工审**：只审最先推出去的前 200 个左右。审核页显示封面、标题和几条弹幕，按一个键打分。
8. 导出池子，提交到这个仓库。

### 古早野生感的标准

从维护者喜欢的几个老视频（逆风笑的 GMOD 躲猫猫、逍遥散人的 I wanna、卑鄙马维斯的恶搞广告、潮汕英豪传、裴美丽的 Wii 实况等）里总结的：

- 做的人能用的东西很少，想做的东西很大，差距没藏起来。
- 真人、真地方：演员是朋友本人，场景是自己的小区、村子、桥下。
- 痕迹都留着：录屏软件水印、视频网站水印、曝光过度、错字、不剪的失误。
- 说话的人很真：用自己的嗓音直接对着看的人说话。
- 结尾常常突然认真，比如给观众道谢、讲自己的故事。
- 很多年后还有人反复回来看，弹幕里一层层的「XXXX 年前来考古」。

## 首页脚本

- 拦下首页请求推荐的那个接口，换成池子里的视频，按 B 站原来的格式返回，让 B 站自己画卡片。比直接改网页元素更不容易被改版搞坏。
- 人工审过的按分数先出，没审过的排在后面；同一个人看过的尽量不重复（记在本地）。
- 发布在 Greasy Fork 和脚本猫。国内打不开 Chrome 商店，网友可以从 Edge 商店装篡改猴。

## 步骤

1. 在维护者登录的浏览器里试一遍接口：哪些能用、要不要签名、多快会触发风控。
2. 建池脚本：种子 → 往外找 → 筛年份 → 机器打分 → 导出。
3. AI 打分，用收藏夹检验。
4. 审核页，审前 200 个。
5. 首页脚本。
6. 发布，在 B 站宣传。

## 以后再做

- **按网友的关注推老视频**：读一次网友的关注列表，缓存在本地；池子里他关注的 UP 主的老视频优先出现。只在池子里找，不替网友去爬，免得给他招来风控。所以池子要收得广，多收各个 UP 主早年的视频，才容易对上。
- 网友投稿老视频的通道。
